# 2025 학습 → 2026 고정 모델 평가

- 학습: 2025년 209시리즈. 후보 선택용 내부 시간순 평가 159시리즈.
- 60개 후보의 2025년 정확도로 선택: 최근 5세트 15분 1,000골드 이상 리드율 차이 + Bo5 여부.
- 모델: 2→16→8→1 MLP, seed 42/43/44 확률 평균. 최종 epoch 1/38/1. 모델과 scaler는 2025년만 학습.
- 평가: 2026-01-14 ~ 2026-09-12, 186시리즈. 이전 경기의 기록만 입력에 반영하고 재학습하지 않음.
- MLP: 109/186, accuracy 58.60%, log loss 0.6886, Brier 0.2477, ROC-AUC 0.6360.
- 동일 피처 logistic regression: 109/186, accuracy 58.60%, log loss 0.6661, Brier 0.2367.
- 2025년 승률 고정 기준: 94/186, accuracy 50.54%.

이미 2026년을 열람한 연구 과정이므로 독립적인 미관측 test라는 주장은 하지 않는다. 후보 선택 점수는 다중 비교로 낙관적일 수 있다. 완료된 승수로 복원한 Bo3/Bo5는 실제 예측 시 대회 형식이 알려져 있다고 가정한다. 이번 실험은 배포 파일을 변경하지 않는다.

새 노트북: ../../02_year_holdout.ipynb
실행: 프로젝트 루트에서 `.venv/bin/python -m backend.training.year_holdout`
